# Rerun 1.2.1

Rerun is a helper program that plays Grand Summoners for you on BlueStacks. Version 1.2.1 adds the newest **GS Companion** work to Rerun, which was not merged when 1.2.0 was built, and fixes one link that the new Account Manager layout had broken. Download **Rerun-1.2.1.zip** below, unzip it, and run `Rerun.exe`. Your data is kept.

**Please read first:** Grand Summoners may not allow macros, bots or automation. Using Rerun can lead to account limits, suspension or a permanent ban.

## What changed

**1. GS Companion updates (the Companion tab).**
- A **Bosses & Events** page, and Quests, Crests and Units areas that link to each other.
- A **Team & Damage** page: add units to a team and see the damage it would do against a boss.
- A newer data updater: the "Update data" button can now also fetch boss and event guides, equipment and the team/damage numbers. It makes polite, one-at-a-time requests to gscompanion.com. The data it downloads is kept on your computer and is not part of the Rerun download.

**2. A fix.**
- In the Companion's Units list, "show in Rerun's Units" used to jump to a fixed tab number. With the 1.2.0 layout that would have landed on the wrong tab. It now opens the Units section inside Account Manager and selects the unit.

Everything from 1.2.0 (Account Manager, Macro Farming, scanning gems, gold and Rank) is unchanged.

## What has and has not been checked

- **Checked automatically:** all 31 groups of Rerun tests pass, and all 21 Companion page tests pass (they need the Companion's downloaded data, which I fetched for the test run).
- **Not checked:** the two calculator comparison scripts in `gsc_app` (they need extra setup). The Team & Damage numbers have been tested by the Companion's own tests, but I have not compared them against the game. The new features from 1.2.0 still have not run on the real game and are BETA.
- The file is still not code-signed, so Microsoft Defender may still complain.

## How to install

1. Close Rerun if it is running. Copy your old folder somewhere safe as a backup first.
2. Unzip **Rerun-1.2.1.zip** and run `Rerun.exe`. Putting it in your existing Rerun folder (replacing the old `Rerun.exe`) keeps your data.
