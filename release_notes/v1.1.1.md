# Rerun 1.1.1

Rerun is a helper program that plays Grand Summoners for you on BlueStacks. Version 1.1.1 is a small update that fixes one thing that was missing in 1.1.0: Rerun now knows where to look for updates. Download **Rerun-1.1.1.zip** below, unzip it, and run `Rerun.exe`.

## What changed

**1. Rerun can now update itself.**
Version 1.1.0 (and 1.0.3) had no update address, so the "check for updates" feature had nowhere to look and stayed off. From 1.1.1 on, Rerun checks an address on GitHub Pages (https://king-clash.github.io/ReRun). It can download two kinds of updates:
- New templates (the little pictures Rerun looks for on screen) and routines, without a new download. Anything you captured or edited yourself is kept, not overwritten.
- New versions of `Rerun.exe`. Rerun downloads it, swaps it in when you close the program, and keeps your old one as `Rerun.old.exe`.
Everything is digitally signed, and Rerun refuses anything whose signature or checksum does not match, so a fake update cannot get in.
**You must install 1.1.1 by hand one time.** Copies of 1.1.0 and older have no address built in and cannot update themselves.

**2. Rerun.exe now has proper "file details".**
Right-click Rerun.exe, then Properties, then Details: it now shows a name, description and version. Programs with no details look anonymous to Microsoft Defender, so this may reduce false alarms. It is not a guarantee, and the exe is still not code-signed.

## What has and has not been checked

- **Checked automatically:** all the test groups pass, and the release zip passed the leak check (no keys, stats or personal data inside).
- **Checked after publishing:** that the update address answers and the signed list of updates is valid.
- **Not checked yet:** a real older-style install downloading and applying a new version through the address, because no newer version exists yet. The first real update will be the test. Defender's reaction to the new file details is also not confirmed.
- All the 1.1.0 settings are still not checked on the real game.

## How to install

1. Close Rerun if it is running. Copy your old folder somewhere safe as a backup first.
2. Unzip **Rerun-1.1.1.zip** and run `Rerun.exe`. Putting it in your existing Rerun folder (replacing the old `Rerun.exe`) keeps your data.
