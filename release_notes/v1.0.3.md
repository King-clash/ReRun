# Rerun 1.0.3

Rerun is a helper program that plays Grand Summoners for you on BlueStacks (farming crests, quests and more). This is a big update: it brings together everything built since version 1.0.2. Download **Rerun-1.0.3.zip** below, unzip it, and run `Rerun.exe`.

## The most important changes

**1. Rerun now asks for a key when it opens.**
You get a key from whoever runs Rerun (it is made with the separate Key Generator tool). Paste it into the sign-in window. A key can last from an hour to a lifetime, and it can be locked to one PC. The top of the window shows a countdown of how much time is left. When a key runs out, every running script stops and Rerun asks for a new one. After you sign in you will also see a "Work In Progress" notice, which just means the program is still being built.

**2. Crest farming now starts from the Home screen.**
Before, you had to put the game on the right screen before pressing Start. Now Rerun gets itself to the Home screen first (it closes pop-ups and presses the Back button as needed), then walks to Exploring, then Crest Palace, then opens the palace and the quest, and farming begins.
- It will not press Back on a screen where you have a crest waiting for a decision (the Equip Crest screen or a Crest Burst), because that might lose the crest. It stops and asks you to decide first.
- **You need to capture two pictures first** (in the Templates tab, while the game shows that screen):
  1. The palace tile it should tap on the Crest Palace screen. Name it `crest_palace_target` (or `crest_palace_mon`, `crest_palace_tue` and so on for a different palace each day). Cut out just the palace name, not the red "time left" badge.
  2. The title row of the quest to farm on that palace's quest list. Name it `quest_list_entry`. Every palace's quest looks different, so a picture from another palace will not match. Extra palaces can use `quest_list_entry2`, `quest_list_entry3` and `quest_list_entry4`.
  Without the tile picture Crest stops right away and names what is missing. If the quest row does not match, Crest stops after a few tries with a message (it used to wait silently). You can also turn this off with the setting "Always start from the Home screen".
- Palaces rotate, so a picture only works while that palace is in the list.
- Tested on the real game by the maker: from the Home screen, Crest walked to the Crest Palace, opened the palace and quest, and started farming.

## New things you can see

- **Live View at 30 frames per second.** The picture of your game on the Dashboard is now smooth video instead of a photo every few seconds.
- **Units tab.** One tab now shows your units and your Compendium progress: element, race, quests cleared, your target, how far along you are, and what changed since the last scan. Each unit shows its little picture, and unit names are corrected using GS Companion's spelling when it is a clear match. There is also a **Companion** tab with GS Companion built in.
- **Better Discord messages.** Alerts are coloured (gold for a rare crest, red for a problem, green for good news, blue for the rest) and have buttons: Stop, Resume, Screenshot and Start Crest. A live status board message shows each game's status, and the new `/energy` command shows your energy. Only people on your allowed list can press the buttons.
- **New app icon.**
- **Your data follows you.** If you start Rerun from a new folder, it finds your old Rerun folder and offers to bring your settings, stats, history and units over (it copies them and never moves them).

## Behind the scenes

- **Updates without a new download (not switched on yet).** Rerun can now check for new templates and new versions of itself. Everything is digitally signed so it cannot be faked. This stays off until an update address is set.
- **Clean release zip.** This zip was built to be safe to share: the config file inside is blank, and none of the maker's own settings, history or keys are in it. It also includes its own copy of the text reader (Tesseract), so you no longer need ReStart for that.
- **Error log.** Problems that used to be ignored silently are now written to `error.log` next to the program, so they are easier to track down.
- **Build log and test tools.** A list of every build, a one-command test runner, and a script that publishes releases.

## What has and has not been checked

- Checked by automatic tests: 18 test groups all pass.
- Checked on the real game earlier: Past Party selection, the unit scan, Live View speed and the Discord messages.
- Checked on the real game after release: Crest starting from the Home screen and walking to the quest.
- **Not checked on the real game yet:** what the Back button does in the middle of a battle (Rerun presses Back to reach Home from other screens).
- **Not checked yet:** a copy of Rerun updating itself from a real update address, and running this zip on a second PC.

## How to install

1. Close Rerun if it is running. If you already use Rerun, copy your old folder somewhere safe as a backup first.
2. Unzip **Rerun-1.0.3.zip** into a new folder.
3. Run `Rerun.exe` and paste your key. If an old Rerun folder is found, choose "Import" to bring your data over.

The older releases (1.0.1 and 1.0.2) were made before these features and are missing most of them, so use this one.
