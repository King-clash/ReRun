# Rerun 1.1.0

Rerun is a helper program that plays Grand Summoners for you on BlueStacks (farming crests, quests and more). Version 1.1.0 is mostly about making the Crest farm easier to set up and more reliable, and about adding a lot of settings so you can control Rerun without editing files. Download **Rerun-1.1.0.zip** below, unzip it, and run `Rerun.exe`. Your existing settings keep working: every new setting is switched off, or set to the old behaviour, until you change it.

## The changes you will notice first

**1. Crest can find the palace and the quest by name.**
Palaces rotate and every quest looks different, so a picture you cut out one day stops matching later. Crest still tries your pictures first. If none matches, it now reads the words on the screen with Tesseract (the free program that reads text from pictures; Rerun includes it) and picks the palace and quest by name. Settings:
- **Palaces to farm, in order of preference**: a list such as `Cursed Claw, Whirlwind`. Crest uses the first one that is open today.
- **Palaces per weekday**: for example `Mon: Cursed Claw; Sat/Sun: Heavenly Light`. On those days it overrides the list. Days follow the game's day, which restarts at 6 AM (UTC-6), not at midnight.
- **Quest to farm**: the quest name. If you leave it empty and the palace has exactly one quest, that quest is used.
- If a palace is not on screen, or two palaces look equally like your name, Crest stops and tells you what it can read. It never guesses.

**2. Crest goes Home by tapping the Home button.**
The Home button at the bottom of the screen is now tapped first (Rerun ships a picture of it). The phone's Back key is only used when the button is not available. New choices:
- **If it can't reach the Home screen**: stop and tell me (default), restart the game and try again (up to 2 times), or keep trying until I stop it.
- **Allow the Back key**: switch it off if you do not want Rerun pressing Back at all.

**3. Limits for a farming session** (each is off by default):
- **Stop after N minutes** and **Stop at HH:MM**: the batch that is running finishes, then Rerun stops and says "Time limit reached."
- **Keep at least N energy**: Rerun stops instead of drinking a potion when the next run would leave you below that number. It reads your energy bar. If the bar cannot be read it does not stop.
- **Max game restarts per day**: caps how often Rerun restarts a crashed or stuck game. The planned daily restart and maintenance restarts do not count.

**4. Discord and app settings.**
- Discord tab: **Quiet hours** (alerts are still posted but without the @mention, and the hours may cross midnight), **Ping me for** (separate switches for rare crests, stops and problems, finished, and everything else) and what the **daily summary** lists.
- Settings tab: **Start minimized to the tray**, **Start scripts when Rerun opens**, **Confirm before Stop All** (the F12 key and the tray menu never ask, so an emergency stop is always instant) and a **Logging** group (what the log file records, how big it gets, how many files are kept).
- Rerun remembers its window position and the tab you had open. A saved position that is no longer on your screen is ignored.
- Templates tab: a **Suggest Crop** button draws the box for you around a palace tile, a quest row or the Home button. You only press Save.

## Smaller improvements

- A **Log file** (`rerun.log`) now keeps everything shown in the Log tab, and the Log tab now shows lines written before the window opened (it used to start empty).
- When a script ends, one line says how long it ran, why it ended, and how many runs, crests, potions and game restarts there were.
- Stuck reports now say which known screen the game most looked like, which makes problems easier to track down.
- Settings > Setup check shows, for each Crest game, whether it can start from the Home screen or what is missing.
- Rerun warns in the Log tab if `config.yaml` has a setting it does not know or one with the wrong type. Nothing is changed or deleted.

## Behind the scenes

- The big settings window code was split into one file per tab. Nothing about how it behaves changed, and it was checked automatically.
- Tests now run in parallel (about 90 seconds instead of about 4 minutes), there is a code checker (ruff) and a GitHub check that runs on every pull request.
- The release script is safer: it refuses to publish old work, thin release notes or private files, and it adds a checksum file (`SHA256SUMS.txt`) so you can verify the download.

## What has and has not been checked

- **Checked automatically:** all 27 test groups pass and the code checker is clean. These use a simulated game plus saved screenshots of the real game (a palace list and a quest list).
- **Checked on the real game earlier:** Crest starting from the Home screen with pictures.
- **Not checked on the real game yet:** picking the palace and quest by name, the weekday table, the time limit, the energy limit, the "restart and try again" option, the Suggest Crop button, Discord quiet hours and ping switches, and the start options. Treat these as BETA and watch the first runs.
- **Not checked:** what the Back key does during a battle, the GitHub check (it has never run on GitHub), updating from a real update address, and the 13 older BETA scripts.
- **Not added:** "keep farming after a rare crest". Rerun keeps a rare crest by stopping on its screen, and it is not known how the game lets you keep one and continue without risking a crest you wanted.

## How to install

1. Close Rerun if it is running. If you already use Rerun, copy your old folder somewhere safe as a backup first.
2. Unzip **Rerun-1.1.0.zip** into a new folder.
3. Run `Rerun.exe` and paste your key. If an old Rerun folder is found, choose "Import" to bring your data over.
4. For Crest, either capture the palace tile and quest row pictures as in 1.0.3, or fill in the palace and quest names in the Crest settings.
